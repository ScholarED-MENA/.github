# ScholarED on GitHub

This repository holds the public GitHub profile and default community files for the ScholarED organization. To learn about ScholarED, visit [scholared.education](https://scholared.education).

| Path | Purpose |
| :--- | :--- |
| `profile/README.md` | Organization profile shown at [github.com/ScholarED-MENA](https://github.com/ScholarED-MENA) |
| `profile/assets/` | Light and dark profile banners |
| `brand/avatar.png` | Organization avatar (512 × 512) |
| `brand/social-preview.png` | Repository social preview image (1280 × 640) |
| `SECURITY.md`, `SUPPORT.md`, `CODE_OF_CONDUCT.md` | Default policies for repositories in the organization |

The SVG files draw their text as outlines from Newsreader and Source Sans 3 (SIL Open Font License 1.1), so they render the same everywhere. After editing an SVG in `brand/`, re-export its PNG at the size listed above.
